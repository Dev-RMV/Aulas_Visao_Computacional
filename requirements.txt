# Requisitos gerais para rodar TODOS os scripts das 16 aulas do PVA.
# Levantado em 10/09/2026 a partir dos imports dos 219 scripts das aulas 01 a 12 e
# ampliado em 22/09/2026 com as aulas 13 a 16 (353 scripts no total), sempre com as
# versões publicadas no PyPI nessas datas. Detalhes e justificativas em
# achados_dos_zips.md, seção 6.
#
# Caminho automático: `py preparar_ambiente.py` (Windows) ou `python3 preparar_ambiente.py`
# (Linux e WSL) faz tudo o que está descrito abaixo, inclusive obter o Python 3.13.
#
# Python: 3.13 (obrigatório). O TensorFlow 2.21 só tem wheel para 3.10 a 3.13,
# então o 3.14 instalado na máquina não serve. Manualmente, no PowerShell:
#
#   py -3.13 -m venv .venv
#   .\.venv\Scripts\Activate.ps1
#   python -m pip install --upgrade pip
#   pip install -r requirements.txt
#   pip install --no-deps -r requirements_face_recognition.txt
#   pip install --no-deps -r requirements_ultralytics.txt
#
# O segundo pip é obrigatório para as aulas 03 (script 15) e 06. Explicação:
# face-recognition declara dependência do pacote "dlib", que no PyPI só existe como
# código-fonte e exige CMake e Visual Studio para compilar no Windows. O pacote
# dlib-bin traz o mesmo módulo "dlib" já compilado, mas o pip não sabe que ele
# satisfaz a dependência. Por isso face-recognition entra com --no-deps, e as
# dependências dele (dlib-bin, face-recognition-models, Click, Pillow, numpy) já
# estão listadas aqui.
#
# O terceiro pip é só para a aula 13 (scripts 11, 12 e 29, YOLOv8n). O ultralytics
# declara dependência de "opencv-python", que instalaria um segundo módulo cv2 por
# cima do opencv-contrib-python e quebraria o cv2.face. Com --no-deps ele entra
# sozinho, e tudo o que ele usa já está listado abaixo.

# --- OpenCV -------------------------------------------------------------------
# Versão 4.x fixada de propósito: o 5.0 (julho de 2026) mudou a API e o código do
# professor foi escrito para a 4.x. O pacote contrib é um superconjunto do
# opencv-python e é necessário para cv2.face (LBPH, aula 03, scripts 13 e 14).
# Não instalar opencv-python junto: os dois pacotes conflitam no mesmo módulo cv2.
# O SURF (aula 03, script 20) não existe nem no contrib do PyPI, que é compilado
# sem os módulos nonfree; o script já prevê esse caso e cai no ORB.
# O cv2.dnn desta versão lê TFLite (aula 14), ONNX e Darknet (aula 13).
