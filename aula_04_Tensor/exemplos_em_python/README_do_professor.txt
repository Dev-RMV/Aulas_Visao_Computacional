EXEMPLOS — TENSORES EM VISÃO COMPUTACIONAL

Ambiente testado pelo usuário: Python 3.12.2 + TensorFlow 2.17 no Windows.

Instalação sugerida no PowerShell:
  py -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install --upgrade pip
  pip install tensorflow

Execução:
  python 01_compare_escalar_vetor_e_matriz.py

Os exemplos 04 a 10 e 12 usam assets/carro_real.png. Execute os arquivos a partir desta pasta para preservar o caminho relativo.

No Windows nativo, TensorFlow 2.11+ usa CPU. Para GPU NVIDIA/CUDA, utilize WSL2 conforme https://www.tensorflow.org/install/pip
